# 良壤官网

良壤品牌官网项目，使用 React + Vite 构建。

## 本地预览

```bash
npm install
npm run dev
```

## 生成正式文件

```bash
npm run build
```

## 可直接打开的 HTML

`HTML网页文件/index.html` 是已处理过的本地 HTML 版本，可以直接用浏览器打开。

## 项目结构

- `src/`: 网站源码
- `public/assets/site/`: 当前网站使用的图片素材
- `training-gallery.html`: 线下培训相册页源码
- `HTML网页文件/`: 可直接打开的导出版本
- `tests/`: 项目测试
